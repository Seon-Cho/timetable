# timetable

주별 커스텀 시간표 앱입니다. 배포 주소: https://timetable-18v.pages.dev

## 사용법

1. 순공 목표 · 기상/취침 · 이번 주 특별 일정 · 자유시간 · 수업 · 고정 일정을 입력
2. **시간표 만들기**를 누르면 월–일, 30분 단위 주간 시간표가 만들어짐
3. 순공 시간은 빈 시간에 자동 배치 (주중·낮 우선, 요일별로 고르게, 식사 시간 제외)
4. 시간표에서
   - 순공 칸을 누르면 완료(초록), 현재 시각 선이 지나도록 완료하지 않은 칸은 실패(빨강)
   - 순공 · 자유시간 · 고정 일정 칸은 끌어서 빈칸으로 옮길 수 있음
5. **← 뒤로** 버튼으로 돌아가 일정을 수정

## 계정 저장

계정 이름과 비밀번호로 로그인하면 일정이 서버(Cloudflare D1)에 저장되어
다른 기기에서도 불러와 이어서 수정할 수 있습니다. 비밀번호는 해시(PBKDF2)로만 저장됩니다.
로그인하지 않으면 입력 내용은 그 브라우저에만 저장됩니다.

## 구조

- `public/index.html` : 앱 화면 (HTML/CSS/JavaScript 한 파일)
- `functions/api/[[path]].js` : 계정 API (Cloudflare Pages Functions)
- `wrangler.toml` : Cloudflare Pages 설정 (D1 데이터베이스 연결)

`main` 브랜치에 올리면 Cloudflare Pages가 자동으로 다시 배포합니다.
